# MiniDoc 내려받기

PDF에 필기하고, Word 문서를 고치고, 파일을 정리하는 작은 데스크톱 앱입니다.
모든 처리는 내 컴퓨터 안에서만 하고, 원본 파일은 그대로 둔 채 결과를 새 파일로 저장합니다.

## ⬇️ 내려받기

**[최신 버전 내려받기 →](../../releases/latest)**

| 컴퓨터 | 받을 파일 |
|---|---|
| 맥 (M1 이후 Apple 칩, macOS 14.4 이상) | `MiniDoc-버전-mac-arm64.zip` |
| 윈도우 | 준비 중이에요 |

인텔 칩 맥은 아직 지원하지 않습니다.

## 설치 (맥)

1. 받은 zip을 두 번 눌러 풉니다.
2. `MiniDoc.app`을 `응용 프로그램` 폴더로 옮깁니다.
3. **처음 한 번만** 아이콘을 **오른쪽 클릭 → 열기 → 열기**를 누릅니다.
   - 개발자 서명을 받지 않은 앱이라 그냥 두 번 누르면 "확인되지 않은 개발자" 경고가 뜹니다.
   - 그래도 열리지 않으면 `시스템 설정 → 개인정보 보호 및 보안` 아래쪽의 **그래도 열기**를 누릅니다.
4. 다음부터는 그냥 두 번 눌러 열면 됩니다.

## 할 수 있는 일

- **PDF 필기:** 형광펜(글자에 맞춰 반듯하게)·펜·텍스트 메모, 필기 모아 보기, 쪽 돌리기·빼기·순서 바꾸기
- **PDF 정리:** 여러 PDF 합치기, 원하는 쪽만 뽑기, 용량 줄이기, 이미지를 PDF로
- **Word 편집:** 종이처럼 보이는 화면에서 바로 고치기, 고른 글자만 꾸미기, 문서 전체 서식 정리, 표 줄·칸 넣기, 찾기·바꾸기, PDF로 저장
- **그 밖에:** 파일 이름 한꺼번에 바꾸기, 최근 파일, 밝게·어둡게, 자동 복구

처음 켜면 짧은 안내가 나오고, 앱 안에서 ⌘/ 를 누르면 모든 단축키를 볼 수 있습니다.

## 알아 둘 점

- Word의 `실제 페이지 미리보기`와 `PDF로 저장`은 맥에 Pages나 LibreOffice가 있어야 합니다. 처음 쓸 때 Pages 제어 권한을 한 번 묻습니다.
- 열 때 암호가 필요한 PDF는 아직 열 수 없습니다.

## 문제가 생기면

앱 오른쪽 위 `문제 알리기`를 누르고 내용을 적은 뒤 `복사하기`를 눌러, 앱을 알려 준 사람에게 보내 주세요.
앱 버전과 최근 오류가 함께 담기고, 파일 이름과 경로는 가려집니다.
